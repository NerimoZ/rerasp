# re:rasp - Приложение для просмотра расписания ГУАП

## 📱 О проекте

**re:rasp** - это мобильное приложение для студентов ГУАП (Государственный университет аэрокосмического приборостроения), которое позволяет удобно просматривать расписание занятий прямо на телефоне. Приложение работает без интернета после первой загрузки данных и сохраняет выбранную группу.

### 🎯 Основные возможности:
- Выбор группы из списка групп первого института
- Просмотр расписания на неделю с возможностью переключения между верхней (нечетной) и нижней (четной) неделями
- Красивый современный дизайн с градиентами и анимациями
- Показ детальной информации о каждой паре: время, предмет, преподаватель, аудитория, кафедра
- Возможность включить/выключить отображение перерывов между парами
- Сохранение настроек между запусками приложения

- **Базовый URL**: `https://api.guap.ru/rasp-sem`
- **Документация**: `https://api.guap.ru/rasp-sem/swagger/index.html`

## 📱 Как работает приложение

### 1. Первый запуск:
1. Показывается экран загрузки с логотипом
2. Приложение проверяет, есть ли сохраненная группа
3. Если группы нет - переход к выбору группы
4. Если группа есть - сразу показ расписания

### 2. Выбор группы:
1. Пользователь видит поле для ввода номера группы
2. При нажатии появляется список групп первого института
3. Можно искать группу по номеру
4. После выбора группы появляется кнопка "Продолжить"
5. Группа сохраняется в памяти телефона

### 3. Просмотр расписания:
1. Отображается расписание на текущую неделю
2. Свайп влево/вправо для смены дня
3. Переключатель недели (верхняя/нижняя) в правом верхнем углу
4. Кнопка перерывов для показа/скрытия времени между парами
5. Клик по номеру группы в шапке для возврата к выбору группы

### 4. Информация о парах:
Каждая карточка пары содержит:
- Время начала и окончания
- Тип занятия (лекция, практика, лабораторная)
- Название предмета
- Номер кафедры
- ФИО преподавателя и его должность
- Аудитория с указанием корпуса
- Номера групп (если пара для нескольких групп)
